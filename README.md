# Рост доли верифицированных товаров в категории Luxury Fashion (кейс Авито)

**Направление:** Продуктовая аналитика и продуктовая стратегия (C2C-платформа)  
**Инструменты и фреймворки:** декомпозиция метрик, JTBD, UX-аудит, конкурентный бенчмаркинг, SMART-гипотезы, RICE-приоритизация, дизайн A/B-тестирования, матрица рисков.

---

## 1. Контекст и бизнес-цель

Платформа запустила сервис фотоаутентификации секонд-хенд luxury-товаров (обувь, сумки, аксессуары): продавец загружает 5–7 фото, партнёр-эксперт проверяет подлинность, и карточка получает бейдж **«Оригинал»** с доступом в раздел **Авито Премиум**. Однако на текущий момент бейдж имеют только **18%** объявлений — покупатели опасаются подделок, а продавцы не видят достаточной выгоды в прохождении проверки.

**Цель проекта:** увеличить долю активных luxury-объявлений с бейджем «Оригинал» с **18% до $\ge 42\%$ за 12 месяцев** для роста прибыли направления.

### Вводные метрики продукта (из условия кейса)

| Метрика | Значение | Комментарий |
| :--- | :---: | :--- |
| MAU категории Luxury Fashion | 4 млн | Уникальные посетители |
| Активные luxury-продавцы | 90 тыс. | Разместили $\ge 1$ объявления за 30 дней |
| Активные luxury-объявления | 650 тыс. | Текущий объём категории |
| Доля объявлений с бейджем «Оригинал» | **18%** | Целевой показатель: $\ge 42\%$ за 12 мес. |
| Доля завершённых сделок с бейджем | 11% | Оплачено, получено, без открытого спора |
| Конверсия «просмотр $\to$ покупка» | **3.2%** vs **1.4%** | С бейджем против без бейджа ($\times 2.3$) |
| Доля споров «подделка» (7 дней) | **0.2%** vs **2.5%** | С бейджем против без бейджа (в 12.5 раз ниже) |
| Средний чек | 28 000 ₽ | По категории |
| Целевой SLA проверки | $\le 24$ ч | Ограничение пропускной способности экспертов |

## 2. Стадия Discovery: рынок и допущения

На первом этапе изучены глобальные и локальные тренды рынка luxury-ресейла и сервисов аутентификации:
* Прогнозируемый рост мирового рынка подержанных предметов роскоши: **6.7%–11.48% CAGR** (2025–2033 гг.).
* Объём рынка Authentication-as-a-Service превышает **$1.35 млрд** (средняя комиссия — 3–5% стоимости вещи).
* Современные AI-модели проверки подлинности достигают точности **99.1%**; верификация повышает цену подлинных вещей до **+40%** (а использование блокчейн-паспортов — дополнительно на 15–25%).
* На российском C2C-рынке (Юла, WB Ресейл, Мешок) системной верификации нет, а спрос на доверие успешно монетизируют игроки вроде Poizon (лабораторная проверка Unicorn + тройной возврат за подделку).

**Ключевые аналитические допущения для расчётов:**
1. Пропорции из вводных данных отражают реальную структуру сегмента (~120.6 тыс. объявлений с бейджем, из них ~90 тыс. — компании и ~30 тыс. — частные лица при общем соотношении частников к компаниям примерно 4:1).
2. Средняя стоимость фотопроверки — ~350 ₽; стоимость платного размещения для частного лица — 150–400 ₽ (ориентир 250 ₽).
3. Под «просмотром» в воронке понимается целевое действие в карточке (просмотр, сообщение, запрос контакта).

## 3. Диагностика проблемы

### 3.1. Почему только 18% объявлений имеют бейдж (JTBD + UX-аудит)

Разложение пользовательских сценариев по **Jobs To Be Done** выявило двусторонний дисбаланс:

| Сторона | Основная работа (Job) | Барьер к использованию бейджа |
| :--- | :--- | :--- |
| **Продавец (особенно C2C)** | Продать вещь быстрее и по лучшей цене | Неочевидный ROI: дополнительные траты (~350 ₽), усилия на съёмку 5–7 ракурсов и ожидание проверки до 24 ч; попытка заложить цену проверки в чек снижает спрос. |
| **Покупатель** | Купить оригинал с гарантией без риска фейка | Не знает о фильтре «Оригинал», не замечает бейдж в ленте и сомневается в надёжности проверки «только по фото». |

**Визуальный UX-аудит карточек (Авито vs Ozon и Яндекс Маркет):**
* На Авито бейдж «Оригинал» выполнен мелким шрифтом в малоконтрастном цвете и теряется в строке рядом с другими плашками («Скидка», «Можно примерить», «Рассрочка»).
* У конкурентов (Ozon, Яндекс Маркет) маркер оригинальности вынесен обособленно и визуально контрастен, что формирует мгновенный триггер доверия на этапе просмотра выдачи.

### 3.2. Приведёт ли рост доли бейджей к росту дохода

**Да, через 4 механизма** (при контроле операционного риска по SLA):
1. **Рост конверсии и привлечение платёжеспособной ЦА:** CR «просмотр $\to$ покупка» у товаров с бейджем в **2.3 раза выше** (3.2% против 1.4%).
2. **Прямая монетизация услуги** (если экономика проверки положительна).
3. **Снижение операционных издержек:** доля споров по подделкам падает в **12.5 раз** (с 2.5% до 0.2%) $\to$ меньше возвратов, логистических потерь и нагрузки на поддержку.
4. **Стандартизация данных:** унифицированный формат верифицированных карточек упрощает аналитику и ML-моделирование сегмента.

*Критический риск масштабирования:* резкий приток заявок без роста пропускной способности партнёров-экспертов приведёт к пробитию **SLA $\le 24$ ч**, что напрямую ударит по конверсии продавцов.

## 4. Конкурентный бенчмаркинг и адаптация под C2C

| Игроки рынка | Практика решения проблемы доверия | Возможность адаптации под Авито |
| :--- | :--- | :--- |
| **Vestiaire Collective, Entrupy** | Обязательная AI пре-модерация | Внедрение AI-проверки при загрузке фото для отсева явных подделок и оценки потенциала подлинности. |
| **Culture Circle + CheckCheck** | Двойная аутентификация (AI + эксперт) | Двухэтапный конвейер: AI выдаёт первичное заключение, эксперт — финальное; для лотов >100 тыс. ₽ — проверка двумя экспертами. |
| **Maxuria, eBay** | Финансовая гарантия возврата | Компенсационный фонд / 100% возврат при ошибке верификации (высокие риски фрода, применимо на раннем этапе для разгона доверия). |
| **AURA Blockchain, Vestiaire** | Партнёрства с брендами | Прямые интеграции с люксовыми брендами в РФ (по аналогии с кейсом Monochrome) и обогащение баз эталонных фото. |
| **The RealReal** | Физический центр аутентификации | Точечно только для самых дорогих лотов (приём на склад, очная проверка, профессиональная съёмка). |
| **AURA Consortium (LVMH/Prada)** | Блокчейн-паспорта вещей | Долгосрочная опция в рамках партнёрских программ с производителями. |

## 5. Генерация и приоритизация гипотез (SMART + RICE)

Сформировано 5 гипотез в формате SMART. Приоритизация выполнена по **RICE** (шкалы: Reach и Confidence — от 0 до 1; Impact и Effort — от 1 до 10):

| # | Гипотеза | Ожидаемый прирост | Ключевой риск | R | I | C | E | **RICE** |
| :---: | :--- | :---: | :--- | :---: | :---: | :---: | :---: | :---: |
| **2** | **Буст в ранжировании для объявлений с бейджем** (за 4 мес.) | **+12 п.п.** | Негатив и падение просмотров у продавцов без бейджа | 1.0 | 8 | 0.8 | 2.5 | **2.56** |
| **5** | **Акция «Первая верификация бесплатно»** (за 6 мес.) | +8 п.п. | Прямые затраты на оплату экспертов; низкая активация | 0.9 | 5 | 0.8 | 2.0 | **1.80** |
| **4** | **Внедрение AI-модуля проверки** (за 6 мес. с обучением) | **+16 п.п.** | FP/FN-ошибки модели подрывают доверие; нужен датасет | 1.0 | 9 | 0.8 | 5.0 | **1.44** |
| **1** | **Интерактивный мастер-помощник съёмки фото** (за 6 мес.) | +7 п.п. | Сложность распознавания фото; навязчивость подсказок | 0.9 | 5 | 0.6 | 3.0 | **0.90** |
| **3** | **Упрощённый трек для продавцов с 5+ проверками** (за 3 мес.) | +6 п.п. | Злоупотребления (продажа реплик после набора истории) | 0.3 | 3 | 0.6 | 1.5 | **0.36** |

**Стратегический вывод:** в первую очередь берётся в работу **Гипотеза 2 (RICE = 2.56)** — бесплатный буст в выдаче плюс визуальный редизайн бейджа. Для достижения годовой цели ($\ge 42\%$, т.е. +24 п.п.) рекомендуется параллельно запускать R&D по **Гипотезе 4 (AI-модуль, +16 п.п.)**, что также снимет узкое горлышко по SLA и позволит ввести двухуровневую верификацию (AI-галочка vs эксперт).

## 6. План реализации, дизайн эксперимента и риски (Гипотеза 2)

### Бэклог внедрения
1. Аудит текущих алгоритмов ранжирования и редизайн визуального отображения бейджа «Оригинал» в выдаче.
2. Разработка прототипа изменений и подготовка инфраструктуры под эксперимент.
3. Проведение A/B-теста $\to$ анализ результатов, калибровка весов буста, раскатка.
4. Маркетинговая кампания для привлечения целевого трафика в сегмент.
5. Пост-мониторинг метрик и сбор качественной обратной связи от продавцов и покупателей.

### Дизайн A/B-эксперимента и UX-исследований
* **Метод:** рандомизированный контролируемый A/B-тест.
* **Единица рандомизации:** покупатель, выполняющий поиск в категории Luxury Fashion.
* **Группы:** Control (A) — стандартная выдача и текущий бейдж; Test (B) — повышенный вес объявлений с бейджем + обновлённый контрастный бейдж.
* **Размер выборки и срок:** 10% от MAU категории (400 тыс. пользователей), длительность **2–4 недели** (одежда в сегменте собирает >130 просмотров за первые 2 дня, обувь — ещё больше, что обеспечит достаточную мощность).
* **Критерий успеха:** статистически значимый ($p < 0.05$) рост доли кликов по объявлениям с бейджем при отсутствии критической деградации общего пользовательского опыта.
* **Дополнительно:** юзабилити-тестирование и интервью с продавцами до/после запуска + опрос покупателей тестовой группы по новому UI бейджа.

### Система метрик

| Категория | Метрики | Зачем отслеживаем |
| :--- | :--- | :--- |
| **Целевая (North Star кейса)** | Доля активных объявлений с бейджем «Оригинал» | Главный KPI проекта (динамика ежедневно/еженедельно) |
| **Вспомогательные (Proxy)** | CTR карточек с бейджем, CR «просмотр $\to$ покупка», число заявок на верификацию, средняя позиция в выдаче, глубина просмотра и время на сайте | Подтверждение механики буста, спроса со стороны покупателей и отклика продавцов |
| **Защитные (Guardrail)** | Bounce rate, жалобы продавцов, просмотры объявлений без бейджа, споры «подделка», **SLA проверки ($\le 24$ ч)** | Контроль релевантности поиска, оттока C2C-продавцов и качества верификации |

### Матрица рисков и митигация

| Риск | Вероятность | Влияние | Стратегия митигации |
| :--- | :---: | :---: | :--- |
| **Негативная реакция продавцов без бейджа** *(главный риск)* | Средняя | Высокое | Коммуникация ценности (борьба с «супер-фейками», рост доверия); мягкий дополнительный буст для объявлений, соответствующих правилам верификации (5–150 тыс. ₽, 1 вещь, Авито Доставка) с онбордингом в проверку. |
| **Перегрузка партнёра-эксперта (пробитие SLA)** | Средняя | Высокое | Подключение дополнительных контрагентов-экспертов и параллельный запуск AI-премодерации. |
| **Технические ошибки в ранжировании** | Средняя | Среднее | Поэтапная раскатка через A/B-тест, алертинг по средним позициям и Bounce rate. |
| **Недостаточный прирост доли бейджей** | Средняя | Среднее | Комбинирование с Гипотезой 5 («первая проверка бесплатно») и Гипотезой 4 (AI). |
| **Злоупотребления и накрутки** | Низкая | Высокое | Антифрод-мониторинг жалоб на подделки и выборочный повторный аудит. |
| **Искажение релевантности поиска** | Низкая | Среднее | Ограничение максимального коэффициента буста, контроль глубины просмотра и CTR. |

## 7. Выводы и план дальнейшей проработки

В ходе выполнения кейса проведены стадия Discovery, конкурентный анализ, UX-аудит, мини-кастдевы с покупателями сегмента, сформулированы и приоритизированы гипотезы, а также собран пошаговый план валидации приоритетного решения.

**Что планируется сделать на следующем этапе (при расширении проекта):**
* Рассчитать детальную **unit-экономику** (стоимость проверки, ожидаемый прирост GMV/комиссии, срок окупаемости акции бесплатной первой проверки и затрат на разработку AI).
* Провести серию глубинных интервью с частными продавцами luxury-сегмента для уточнения ценовой эластичности услуги.
* Подготовить кликабельные **UI-макеты** нового бейджа и фильтров для коридорного тестирования.
