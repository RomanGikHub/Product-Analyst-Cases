# Neiry Music Emotion Tracker (Windows / Python)

Десктопное приложение для **Neiry Headband**, которое в реальном времени отслеживает эмоциональный и психофизиологический отклик во время прослушивания музыки (Spotify и любые системные плееры через Windows SMTC), записывает полные сессии в **HDF5** и накапливает адаптивный профиль каждого трека между сессиями в **SQLite**.

## Структура проекта

- `app.py` — запуск приложения.
- `config.py` — пороги качества сигнала (1000 кОм, MEMS), минимальная длительность трека (20 с), коэффициент затухания весов `RECENCY_DECAY_LAMBDA`.
- `core/capsule_bridge.py` — интеграция с вашей версией `CapsuleClientPython` (`DeviceType.Headband`, `DeviceLocator.with_logs_path`, `Emotions`, `Cardio`, `Productivity`, `PhysiologicalStates`, `Calibrator`, `MEMS`, `Resistances`, `EEGArtifacts`) + встроенный `Demo`-режим без повязки.
- `core/media_monitor.py` — чтение текущего трека из Spotify и системных плееров через Windows SMTC.
- `core/hdf5_store.py` — поточная запись/чтение HDF5-сессий (совместимо со структурой Neiry 3.0 + разметка треков).
- `core/emotion_engine.py` — оценка эмоций относительно бейслайна, фильтрация по качеству сигнала и экспоненциальная ребалансировка весов между сессиями.
- `core/track_db.py` — постоянная база треков и сохранённых профилей калибровки (SQLite).
- `ui/main_window.py` — интерфейс с 3 вкладками: **Сессия (Live)**, **Отчёт / HDF5**, **Библиотека треков**.

## Установка и запуск на Windows

1. Распакуйте архив в рабочую папку (например, `C:\Projects\neiry_music_tracker`).
2. Скопируйте внутрь этой же папки (рядом с `app.py`):
   - папку **`CapsuleClientPython\`** из вашего пакета CapsuleAPI;
   - файл **`CapsuleClient.dll`** (64-bit).
3. Установите зависимости (Python 3.11+):
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\activate
   pip install -r requirements.txt
   ```
4. Запустите приложение:
   ```powershell
   python app.py
   ```

## Как проверить работу

- **Быстрый тест без повязки:** выберите устройство **`Demo (без повязки)`**, нажмите «Подключить и начать сессию», включите любой трек в Spotify — программа автоматически подхватит его через Windows SMTC, нарисует живые графики, запишет `.h5` в `data/sessions/` и сохранит статистику трека в «Библиотеку треков».
- **С реальным Neiry Headband:** выберите **`Headband`**, включите «Биполярный режим», дождитесь зелёного индикатора контакта (< 1000 кОм), пройдите «Быструю калибровку» (профиль сохранится в SQLite, в следующий раз можно нажать «Импортировать прошлую») и запускайте плейлист в Spotify.
